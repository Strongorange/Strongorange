# 이찬휘 (Chanhwi Lee)

웹 화면부터 서버, AI 기능, 배포까지 직접 만드는 개발자입니다.

- 툴디(타라 티피에스)에서 디자인 에디터의 AI 기능, AI 템플릿 생성 서버, 템플릿·이미지 검색, 해외 결제를 만들고 있습니다.
- 네이처컴바인드에서는 공유 자전거 앱과 위치 기반 앱을 React Native로 만들어 출시했고, AI 캐릭터 채팅에 쓴 검색 서버와 LLM 서버를 만들었습니다.

## 기술

- 화면: TypeScript, React, Next.js, React Native
- 서버: Node.js(NestJS, Fastify, Express), Python(FastAPI), PostgreSQL, Redis
- AI: Gemini API, OpenAI API, vLLM, Qdrant, Chroma
- 인프라: AWS, Docker, Terraform
